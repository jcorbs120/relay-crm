Email capture

{{ chk('sync_auto', "Automatic sync: scan each connected person's Inbox and Sent Items and log every email with external contacts.") }} {{ chk('sync_capture', 'BCC / forward capture: also log anything in each person\'s capture folder, and in the shared team mailbox if you set one below.') }}
Each person can drag emails into this Outlook folder, or set a rule like "sent to name+crm@yourfirm.com, move to {{ S.capture_folder or 'CRM' }}" and BCC that address.
Anyone can BCC or forward here. Relay works out which teammate sent or forwarded it and credits them.
